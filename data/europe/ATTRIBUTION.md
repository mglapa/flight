# Map data sources

Baked by `tools/bake_europe.py`.

- **Elevation and bathymetry:** AWS Terrain Tiles (Terrarium encoding, zoom 9),
  derived from SRTM, GMTED2010, ETOPO1 and other sources. Includes data from
  EU-DEM produced using Copernicus data and information funded by the European
  Union. See https://github.com/tilezen/joerd/blob/master/docs/attribution.md
- **Coastlines, urban areas, populated places:** Natural Earth (public domain),
  https://www.naturalearthdata.com/
